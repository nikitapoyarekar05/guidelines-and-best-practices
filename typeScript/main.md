# TypeScript is a typed superset of JavaScript

- But it doesn't add anything now or more to JS. It just allows you to write JS in a more precise manner so that your code faces less error dueing runtime (when you are writing code).
- At the end, the TS code is converted to JS (Browsers do not understand TS, they only know JS)
- TS doesn't reinvent JS. It is just JS written in a more precise manner (
  considering behavior or appearance of everything that we write)
  )
- Use the superpower of TS whenever you are writing the code

## TypeScript is all about Type Safety

- Eiliminates JS's odd behavior
  ex. 2 + undefined -> NaN, avoid this by adding types to operands
- TS is not a new programming language. It is a type wrapper around JS.
- TS does static checking as it is a STATIC CHECKER - checks while you are writing JS code for correct syntax, make sures tjat numbers is added with numbers, and not strings
- Catches potential errors (syntax and existance of variables errors) before compiling the code i.e. at runtime
- Yes, you write more code in TS as compared to JS, but the probability of TS code crashing at a later stage is very very less
- usually written in .ts and .tsx file

## Compiled and Transpiled is same in TS

- TS is a development tool. It is a layer on top of JS that helps you write better code
- TS is transpiled/compiled into JS
