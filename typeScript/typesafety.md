# Global installation command

- If you are using it as a development tool, you can install TS as a dev dependency. The command is `npm install typescript --save-dev`

- You can install it globally too. The command is `npm install -g typescript`

- Command is independent of platform OS. Use it on Linux, MAC, or Windows.
  - You may need to use this command by runnign Git Bash as an administrator
  - For linux and mac, just run this with sudo and add a password

- After installation, TS gives a access to the command `tsc`. This allows execution of the TS file
- `tsc --version` or `tsc -v` provides TS version
- To run TS file, use th command `tsc name-of-the-file.ts`. This is because we can't run TS directly.
